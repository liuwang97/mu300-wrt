# kernel/

Linux 7.2 (`VERSION`) for the ZTE F50 and the ZTE U30 Air, and the kernel bundle the root filesystem installs.
Read the root `CLAUDE.md` first. This tree never reads a file under `openwrt/`: what the system needs from it is in
`docs/contract.md`, and nowhere else.

## What is here

- `build.sh` — fetches `linux-$VERSION` into `$MU300_SRC` (default `/src`), checks kernel.org's signatures
  (`verify-kernel-src.sh`, `keys/`), applies `port/install.py` and `patches/*.patch`, configures (allnoconfig +
  `mu300-mainline.config` + `all-modules.py`: every tristate the boards can use becomes a module) and builds `Image`
  into `$MU300_OUT` (default `kernel/out`). Cross-compiles with `aarch64-linux-gnu-` off arm64.
- `build-modules.sh` — the kernel's own modules and the out-of-tree ones in `modules/` (wcn_bsp, sprd_wlan_combo,
  sprdbt_tty, sprd_modem, sprd_pmic_wdt, sprd_ddr_dfs, mu300_thermal, ums9620_lpintc), flat in `$MU300_OUT/modules`;
  `check-dt-modules.py` fails the build when a module would bind to the stock device tree by itself.
- `make-bundle.sh OUT.tar.gz` — the bundle of `docs/contract.md`: Image (`wrap-image.py`), the generic ramdisk segment
  (`initramfs/build-boot-image.py`), every module, `autoload-blocked`, `contract`. It audits the build first
  (`audit-bundle.py`, `check-autoload-blocked.py`, vermagic, `initramfs/module-order.txt`).
- `initramfs/` — `init` (board, USB gadget and early DHCP, Linux slot and misc, root on the eMMC region, the GPT
  partition `mu300root` or an SD card labelled `mu300sd`, fsck, CPU voltage offset, boot tries, switch_root),
  `tools.sh` (static busybox, logdw, e2fsck), `ueventd-perms.sh` (generated by `gen-ueventd-perms.py`).
- `port/` — SoC drivers ported into the tree (clocks, pinctrl, PCIe, regulators, cpufreq with the voltage offset,
  thermal, LEDs, watchdog, firmware, USB PHY); `port/install.py` copies them and edits Kconfig/Makefiles by anchor.
- `patches/` — mainline patches, numbered; each says why in its own description.
- `docs/` — hardware, boot chain, drivers, vendor modules.
- `tests/` — `cd kernel/tests && python3 -m unittest`.

## Keep

- Both boards: F50 and U30 Air (charger bq256xx/SGM41513, fuel gauge, Type-C/PD via `TYPEC_UMP9620`).
- Bluetooth (`modules/sprdbt_tty`, patch 0002), the audio DSP reservation (patches 0003 and 0022), the SD card root
  and its host order (patch 0014, `mmc_disks` in init).
- No GPU module out of the tree: the GPU gets Panfrost (in-tree) when it is brought up; never the vendor Mali DDK.

## Rules

- Change a patch by editing the `.patch` file; it must apply to `VERSION` with `patch -p1` (build.sh stops otherwise).
  A new patch takes the next free number and explains the why in its header.
- A config option that Kconfig drops stops the build: fix the option, never silence the check.
- The initramfs is part of the kernel: it ships with the Image and insmods by path, so its modules must match the
  kernel's vermagic. It reads only what `docs/contract.md` lists from the system it boots.
- Out-of-tree modules carry no compatibility code for kernels other than 7.2.
- A test that needs a file of the root filesystem's tree belongs in that tree's tests, with a fixture.

## Building here (WSL)

```sh
MU300_SRC=$HOME/mu300src bash kernel/build.sh
MU300_SRC=$HOME/mu300src bash kernel/build-modules.sh
sh kernel/make-bundle.sh mu300-kernel-7.2.tar.gz      # tools.sh needs docker with linux/arm64 for e2fsck
```
